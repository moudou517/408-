# 408 真题复习中心 · 交付说明

本目录基于**本地 18 套 408 真题（2009–2026）+ 对应年份《真题解析》**整理。
共 **830 题**、127 个叶子知识点；其中 **686 道选择题有官方答案**、**119 道综合题有参考答案与思路（116 道已提取文字版）**。

## 一个入口

**桌面只有「408 复习中心」一个图标**，双击即进 `index.html`，里面三个门：

| 门 | 页面 | 用途 |
|---|---|---|
| **01 知识体系** | `map.html` | 四科 → 章 → 知识点，**每个知识点直接连到对应题库**（刷选择 / 刷大题 / 看题） |
| **02 题库** | `browse.html` | 按科目/章/知识点检索全部 830 题，可搜索、可直达单题 |
| **03 刷题** | `quiz.html`（选择题 686）<br>`bigq.html`（综合题 119） | 选题库 → 直接开刷 |

右上角 **「📱 平板连接」** 按钮弹出二维码，平板扫码即可打开刷题页。

`快捷方式\` 里还有 `.bat` 兜底，以及两个平板相关脚本：

- `启动局域网服务_平板用.bat` —— 平板访问时用它，窗口常驻并打印全部地址
- `允许平板访问_加防火墙规则.bat` —— 平板连不上时先跑它（弹 UAC，点"是"）

## 刷题：按考点选，不是只有随机

**选择题（`quiz.html`）** 支持 8 种题库：

| 分类 | 说明 |
|---|---|
| 全部题目 | 686 道 |
| **专题题库** | 10 个打包专题（树与图 65 · 协议细节 64 · CPU与IO 59 · Cache 44 · 内存文件 43 · 数据表示 40 · 排序查找 36 · 子网 26 · PV 13 · 流水线 12） |
| 按科目 / 按章节 | 4 科 / 25 章 |
| **按知识点** | **113 个知识点逐条选**，带【必】/【高】标记 |
| 按年份 | 按整卷刷 |
| **按考频** | 必考级（≥14/18 年）/ 高频 / 常考 / 低频 |
| 错题本 | 只刷做错的 |

**格式**：乱序 / 按年份顺序；**即时判分**（边做边看解析）或 **交卷判分**（整套做完再对答案，可翻页改答案）；题量 10/20/50/全部。

**综合题（`bigq.html`）**：先看题干自己写思路 → 按 **「显示参考答案与思路」** 再看答案 → 自评「会了 / 不会」。
支持按科目/章节/知识点/年份/错题筛选，键盘 `空格` 显示答案、`1` 会了、`2` 不会。

## 知识体系 → 题库的连通方式

`map.html` 里每个知识点右侧有三个入口，全部带参数直达：

```
刷选择 →  quiz.html?kp=DS.7.6
刷大题 →  bigq.html?kp=DS.7.6
看题   →  browse.html#kp=DS.7.6
```

科目/章节层级同理（`?subj=DS`、`?chap=DS|图`）。所以「从框架进入」和「进题库刷」是一件事，不用来回找。

## 平板怎么连

**扫码**：双击桌面图标 → 右上角「📱 平板连接」→ 平板相机扫二维码。
**手输**：`<电脑IP>:8000`（资料入口）或 `<电脑IP>:8000/quiz.html`（刷题）。

**IP 会变**（换 Wi-Fi、重连路由器后就变），所以别抄死地址：服务每次启动都会重算 IP，并刷新
`qr_quiz.png` 与 `data/connect.json`；入口页的二维码弹窗和连接页都是**实时读取当前地址**。
想看当前地址：双击桌面图标 →「📱 平板连接」，或看服务窗口启动时打印的横幅，或读 `out/data/connect.json`。
连不上按顺序查：① 同一 Wi-Fi ② 服务窗口还开着 ③ `允许平板访问_加防火墙规则.bat` ④ 地址前面加 `http://`。

**代码排版** —— 之前提取时把连续空白压成了一个空格，C 代码的换行和缩进全丢了。现在：

- 提取阶段**保留换行与行首缩进**，只压行内多余空格（解析平均长度 729 字，116/119 带换行）
- 页面用一套轻量 Markdown 式渲染 `richText()`：
  - 连续行若是「代码样」（含 `{};`、有缩进、或以 `for/while/int/void/struct…` 开头）→ 渲染成 `<pre class="code">` 等宽块，**缩进原样保留**、可横向滚动
  - 表格式短行（参数/数值/说明）也走等宽块，比挤成一行好看
  - 其余按自然段合并（中文直接连、英文加空格），自动换行
- 已应用到：大题题干与解析、选择题解析、题库索引的展开面板

## 发给同学 / 换电脑：用离线包

**`.lnk` 快捷方式搬不走**。它里面存的是写死的绝对路径（目标 `D:\Python\pythonw.exe`、参数 `E:\CST\408\tools\launch.py`），
所以文件夹一旦被复制到别的盘或别的电脑，双击就报「快捷方式指向的驱动器或网络连接不可用」——**不是资料坏了，是快捷方式指不到那儿了**。
同理，`快捷方式\` 里的 bat 如果还写着 `E:\CST\408`，换台机器也会失败。

**正确做法**：跑 `python tools\make_share.py`，生成

```
分享\408真题复习包\          ← 目录（62 MB / 481 个文件）
分享\408真题复习包.zip       ← 直接发这个（53.8 MB）
```

包里只放真正要用的东西（**不带** `.pylibs` 370 MB、`work\`、原始 PDF）：

| 文件 | 作用 |
|---|---|
| `双击这里开始复习.bat` | 用 `%~dp0` 自推目录，搬到哪都能用 → 打开 `out\index.html` |
| `创建桌面快捷方式.bat` | 按**当前**路径重建桌面图标（配 `408.ico`），搬完位置再点一次即可 |
| `使用说明.txt` | 给对方看的三分钟说明 |
| `out\` | 六个页面 + 两个 PDF + `qimg\`(35 MB) + `fig\`(7.3 MB) |

**对方什么都不用装**：不用 Python、不用服务器、不用联网。题目/答案/解析全部内嵌在
`quiz.html`/`browse.html`/`bigq.html` 里，`report.html` 的图表是内嵌 base64，
`index.html` 的平板二维码模块在离线包里已自动去掉。整个包随便改名、换盘、解压，双击即用。

只有两点要注意：

- `out\qimg\`、`out\fig\` 必须跟着 HTML 一起走（图片是外链文件，不是内嵌）
- 平板模式（`启动局域网服务_平板用.bat`）需要 Python，是自己电脑上用的功能，**分享包里不包含**

**临时救急**：如果已经把整个 408 文件夹发出去了，让对方**直接进 `out\` 双击 `index.html`** 就能用，
只是没有图标和说明文字——数据是全的。

## 数据口径与局限

- **题号即科目**（选择题 Q1–11 DS / 12–22 CO / 23–32 OS / 33–40 NET），已逐题核对；**综合题按内容判科**（个别年份不按科目排序，如 2014 年 Q42 实为图论题）。
- **选择题答案**：部分年份是页首「参考答案」表格（在 PDF 文字层里被打散），用 **OCR + 坐标重建表格**还原，并逐题核对了 2009/2011/2013 截图；最终 **720/720**（四选项分布 A150/B177/C187/D172，均匀）。
- **综合题解析**：2019/2021/2023 的解析 PDF 是扫描件，已 OCR 补齐；**2025 年 43、46、47 三题**因源 PDF 用符号字体，题号被抽成乱码字符，正则无法定位，故缺解析（页面会提示）。
- 分类覆盖率 **830/846 ≈ 98.1%**；26 道选择题因选项是图片无法文字化，未进刷题器。
- 练习记录（错题本、统计）存在浏览器 **localStorage**，**按设备各存一份**。
